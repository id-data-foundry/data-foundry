What it is: This is a spatial tracking repository. It holds movement logs and coordinate paths (longitude, latitude, elevation, time) of participants.

How it works: Movement tracking files (GPX or XML formats) are uploaded via the Web UI/API, or coordinates are received in real-time when participants share their location via the Telegram Bot.

What you can do: You can send file arrival alerts to an OOCSI channel or download/export files and metadata as a CSV spreadsheet.
