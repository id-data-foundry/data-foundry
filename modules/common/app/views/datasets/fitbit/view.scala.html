How it works (Workflow Diagram)

What it is: This is a health tracking repository. It stores physiological and activity data retrieved directly from Fitbit wearables.

How it works: Participants authorize access via Fitbit OAuth. Data Foundry periodically calls the Fitbit Web API to sync steps, heart rate, calories, and sleep.

What you can do: Broadcast synced data via OOCSI channels or download physical logs as a CSV spreadsheet.
