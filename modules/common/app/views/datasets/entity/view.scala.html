How it works (Workflow Diagram)

What it is: These datasets act like a digital profile or a "status board". They keep track of the most recent information for a person or an object (like a name or current settings).

How it works: Profiles are updated via HTTP requests (API) or OOCSI messages. When new information comes in, the profile is updated so it always shows the latest state.

What you can do: You can keep other systems in sync via OOCSI or export the latest status of all entities as a CSV spreadsheet.
